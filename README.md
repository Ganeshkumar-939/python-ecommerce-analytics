# E-Commerce Sales Analysis (Python)

## Objective
Analyze e-commerce sales data using Python and Pandas to understand revenue, customer contribution, and product performance.

## Tools Used
- Python
- Pandas

## Analysis Performed
- Loaded CSV datasets using Pandas
- Merged sales, customer, and product data
- Calculated total revenue
- Analyzed revenue by customer
- Identified top-selling products

## Project Structure
- data/ – CSV datasets
- scripts/ – Python analysis scripts
- outputs/ – Results and summaries
